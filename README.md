# anduin

Test bench for multi-agent software construction coordinated through
[Moment](https://github.com/blaiszik/moment-next), the context hub.

Each experiment lives on its own branch, named for the concept under build.
Agents coordinate exclusively through the Moment project brief — tasks,
handoffs, and session notes — never through shared conversation context.

| Branch | Concept |
|---|---|
| `cif-doctor` | Batch CIF validator/fixer for crystallography files |
